# ACCESS AI

**Adaptive Cognitive Companion for Efficient  System Service**

ACCESS AI is a private, local, general-purpose AI companion for conversation, learning, coding, research, automation, and system tasks.

It can create new tools, test and fix its own changes, and apply them with user permission.

## Features

* Local and private
* User-controlled ethics and policies
* Permission-based self-programming
* Testing and rollback
